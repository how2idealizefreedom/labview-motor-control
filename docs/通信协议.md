# 通信协议 · USB CDC ASCII 命令

## 物理层

- STM32 USB 外设配置为 CDC（Communication Device Class），Windows 下识别为虚拟串口 `COMx`。
- 波特率：CDC 是 USB 虚拟串口，波特率参数不影响实际速率；上位机与固件统一写 115200 即可。
- 数据帧：ASCII 字符串，以 `\n`（或 `\r`）结尾。下位机按行缓冲，收到换行才解析。

## 命令集

| 命令 | 格式 | 参数范围 | 返回 | 说明 |
|---|---|---|---|---|
| 设速度 | `S<速度>\n` | -1000 ~ +1000（‰） | `OK\r\n` / `ERR\r\n` | 设电机 A 速度；B 自动 = k·A |
| 设比例 | `K<百分比>\n` | 0 ~ 100 | `OK\r\n` / `ERR\r\n` | k = 百分比/100，如 `K50` → k=0.5 |
| 查状态 | `R\n` | 无 | `A=%+d B=%+d K=%d.%02d\r\n` | 返回当前实际速度与比例 |
| 急停 | `X\n` | 无 | `STOPPED\r\n` | 两电机立即刹车 |
| 帮助 | `?\n` | 无 | `CMD: S+500 K50 R X ?\r\n` | — |

## 示例会话

```
主机 -> S+500
设备 -> OK
主机 -> K50
设备 -> OK
主机 -> R
设备 -> A=+500 B=+250 K=0.50
主机 -> S-400
设备 -> OK
主机 -> R
设备 -> A=-400 B=-200 K=0.50
主机 -> X
设备 -> STOPPED
```

可以看到 A=+500 时 B=+250、A=-400 时 B=-200，`B/A = 0.5` 恒定——这就是线性联动。

## 速度单位说明

速度用**千分比占空比**（per mille）：`+1000` = 正向满占空比，`-1000` = 反向满占空比，`0` = 停止。TIM3 的 ARR = 9999，占空比换算：

```
duty = |speed| * 9999 / 1000
```

方向由 H 桥的 IN1/IN2 电平决定（见硬件接线.md），符号为正=IN1高，为负=IN2高。

## 线性联动的实现（核心）

在 `motor.c` 的 5 ms 调度里：

```c
targetB = (ratio_permille * outA) / 1000;   // B = k * A
outA = ramp(outA, targetA, step);            // A 朝目标平滑
targetB = (ratio_permille * outA) / 1000;   // 用平滑后的 A 重算 B
outB = ramp(outB, targetB, step);            // B 也平滑跟随
```

- `ratio_permille` 是整数（500 = 0.5），全程整数运算，无浮点，无 FPU 依赖。
- B 的 target 由**平滑后的 A** 实时算出，所以加速过程中两轮也严格保持比例，不会因斜坡不同步而失配。
- 斜坡 `step=25`：从 0 到 1000 需要 40 拍 = 200 ms，平滑且响应快。

## 行缓冲解析（抗粘包）

`protocol.c` 逐字节接收，遇到 `\n` 或 `\r` 才 decode 一行：
- 主机快速连发多条命令不会丢帧；
- 半包（换行未到）不会误触发；
- 超长行（>63 字节）自动丢弃，防止缓冲区溢出。
