# 通信协议 · USB CDC

STM32 USB 配为 CDC，Windows 下是虚拟串口 COMx。波特率参数不影响 USB 实际速率，两端统一写 115200。

帧格式：ASCII 字符串，以 `\n` 或 `\r` 结尾。下位机按行缓冲，收到换行才解析。

## 命令

| 命令 | 格式 | 参数 | 返回 |
|---|---|---|---|
| 设速度 | `S<速度>\n` | -1000~1000 (‰) | `OK` / `ERR` |
| 设 k | `K<百分比>\n` | 1~100 | `OK` / `ERR` |
| 查状态 | `R\n` | — | `A=%+d B=%+d K=%d.%02d` |
| 急停 | `X\n` | — | `STOPPED` |
| 帮助 | `?\n` | — | `CMD: S+500 K100 R X ?` |

`S` 只设电机 A。电机 B 由下位机解算，使 `sin(v1) = k·cos(v2)` 成立。

## 示例

```
主机 -> S+500
设备 -> OK
主机 -> R
设备 -> A=+500 B=+500 K=1.00
主机 -> K50
设备 -> OK
主机 -> S+333
设备 -> OK
主机 -> R
设备 -> A=+333 B=+972 K=0.50
主机 -> X
设备 -> STOPPED
```

k=1 时 A 与 B 相等。k=0.5 时 A 被限制在 ±333，B 可达 ±972。

## 解算

相位定义：

```
v1 =  a      · π / 2000
v2 = (1000-b) · π / 2000
```

由 `sin(v1) = k·cos(v2)` 解出 b：

```
cos(v2) = sin(v1) / k
v2      = acos( sin(v1) / k )
b       = 1000 - v2 · 2000 / π
```

要求 `|sin(v1)| ≤ k`，即 `|a| ≤ (2000/π)·asin(k)`。固件按这个上限截断 A，再算 B，避免 `acos` 无解。

`motor.c` 每 5 ms 一拍：先把 A 朝截断后的目标斜坡一步，用平滑后的 A 重算 B 目标，B 再斜坡一步。每拍最多变化 25‰，0 到满速 40 拍（200 ms）。

## 速度单位

千分比占空比：+1000 为正向满占空比，-1000 为反向，0 为停止。TIM3 ARR=9999，换算 `duty = |speed| × 9999 / 1000`。方向由 H 桥 IN1/IN2 电平决定。

## 行缓冲

`protocol.c` 逐字节接收，遇换行才解析一行。连发不丢帧，半包不误触发，超过 63 字节的行丢弃。
