# 通信协议 · USB CDC

STM32 USB 配为 CDC，Windows 下是虚拟串口 COMx。波特率参数不影响 USB 实际速率，两端统一写 115200。

帧格式：ASCII 字符串，以 `\n` 或 `\r` 结尾。下位机按行缓冲，收到换行才解析；超过 63 字节的整帧丢弃。

## 命令

| 命令 | 格式 | 参数 | 返回 |
|---|---|---|---|
| 设速度 | `S<速度>\n` | -1000~1000 (‰) | `OK` / `ERR` |
| 设 k | `K<百分比>\n` | 1~100 | `OK` / `ERR` |
| 遥测 | `T<0\|1>\n` | 0 关 / 1 开 | `OK` / `ERR` |
| 闭环 | `L<0\|1>\n` | 0 开环 / 1 闭环 | `OK` / `ERR` |
| 基本状态 | `R\n` | — | `A=%+d B=%+d K=%d.%02d` |
| 扩展状态 | `V\n` | — | 见下 |
| 编码器 | `E\n` | — | `CA=.. CB=.. RA=.. RB=..` |
| 急停 | `X\n` | — | `STOPPED` |
| 帮助 | `?\n` | — | `CMD: S+500 K100 T1 L1 R V E X ?` |

任何命令都会刷新 500 ms 看门狗。超时后两电机刹车，状态置 `T`。

## 扩展状态帧

`V` 的返回，以及遥测开启后每 50 ms 主动发的一帧（遥测帧以 `>` 开头，其余相同）：

```
A=%+d B=%+d CA=%+d CB=%+d MA=%+d MB=%+d K=%d.%02d ST=%c L=%d
```

| 字段 | 含义 |
|---|---|
| A / B | 实际输出到 PWM 的速度（‰） |
| CA / CB | 斜坡后的目标速度（‰），满足三角约束 |
| MA / MB | 编码器实测速度（‰） |
| K | k，两位小数 |
| ST | `I` 空闲 / `R` 运行 / `T` 超时 |
| L | 0 开环 / 1 闭环 |

## 示例

```
主机 -> S+500
设备 -> OK
主机 -> R
设备 -> A=+500 B=+500 K=1.00
主机 -> K50
设备 -> OK
主机 -> S+333
设备 -> OK
主机 -> R
设备 -> A=+333 B=+972 K=0.50
主机 -> T1
设备 -> OK
设备 -> >A=+333 B=+972 CA=+333 CB=+972 MA=+331 MB=+968 K=0.50 ST=R L=0
设备 -> >...（每 50 ms 一帧）
主机 -> T0
设备 -> OK
主机 -> X
设备 -> STOPPED
```

## 解算

```
v1 =  a      · π / 2000
v2 = (1000-b) · π / 2000

sin(v1) = k·cos(v2)
  =>  b = 1000 - acos( sin(v1)/k ) · 2000/π
```

要求 `|sin(v1)| ≤ k`，即 `|a| ≤ (2000/π)·asin(k)`。固件按此上限截断 A 再算 B。5 ms 一拍，A 先斜坡，再用平滑后的 A 解算 B，斜坡步长 25‰/拍。

## 闭环

`L1` 开启后，目标由斜坡产生，实际 PWM 由两路 PI 根据编码器反馈给出。PI 参数 kp=0.4、ki=1.5，积分限幅 `out_max/ki`。切换时会重置积分器，避免速度跳变。

编码器满速计数率用 `ENCODER_FULL_CPS` 配置，方向用 `ENCODER_A_DIR` / `ENCODER_B_DIR` 配置，需要按实板标定。
