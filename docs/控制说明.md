# 控制结构

## 分层

```
coupling.c  纯算法：限幅、斜坡、sin/cos 解算
pid.c       纯算法：离散 PI，积分限幅
encoder.c   驱动：TIM2/TIM4 正交编码器，5 ms 采样并低通
motor.c     应用：状态机、看门狗、开环/闭环切换、H 桥输出
protocol.c  接口：命令解析、状态帧、50 ms 遥测
```

算法层不含任何 MCU 头文件，可在 PC 上单独编译测试（`tests/test_algorithm.c`）。

## 数据流

每 5 ms 一拍：

```
上位机 S/K/L
    │
    ▼
A 指令限幅 ──> 斜坡 ──> cmdA
                          │
                          └─ 解算 ──> cmdB
                                        │
              ┌─────────────────────────┴──────┐
              │ 开环                            │ 闭环
              │ outA=cmdA, outB=ramp(cmdB)      │ PI(cmdA-measA), PI(cmdB-measB)
              └─────────────────────────┬──────┘
                                        ▼
                                   H 桥 PWM
                                        │
                                   编码器反馈
```

`cmdA` 和 `cmdB` 始终满足 `sin(v1) = k·cos(v2)`。闭环只改变达到目标的方式，不改变两者的关系。

## PI 整定

一阶电机模型（每拍 `meas += (pwm - meas) × 0.15`），目标 600‰：

| kp | ki | 调节时间 | 超调 |
|---:|---:|---:|---:|
| 0.30 | 0.08 | > 6 s 未收敛 | 无 |
| 0.30 | 1.00 | 4.67 s | 无 |
| 0.40 | 1.50 | 3.27 s | 无 |

选用 kp=0.4、ki=1.5。积分项限幅在 `out_max/ki`，即积分贡献不超过输出上限，防止电机饱和时积分绕卷。切换闭环时重置积分器。

实板电机参数不同，这两个值需要在硬件上重新整定。

## 看门狗

任何命令都刷新时间戳。超过 500 ms 没有命令：

- 目标、输出、积分器清零
- H 桥方向脚拉低，PWM 占空比为 0
- 状态置 `T`，`V` 帧可见

收到新命令后自动回到 `RUN`。这条保护用于上位机崩溃或断线时防止电机持续转动。

## 测试

`tests/test_firmware.py` 用 Python 逐行镜像固件逻辑，26 项覆盖：

- 三角约束：4 种 k × 9 个速度点
- 定义域与限幅
- 斜坡步长与时序
- PI 收敛与积分限幅
- 协议解析、非法参数、超长行、CRLF
- 看门狗超时与恢复
- 闭环收敛与模式切换

`tests/test_algorithm.c` 是 gcc 可直接编译的 C 单测，验证 `coupling.c` 和 `pid.c`。
