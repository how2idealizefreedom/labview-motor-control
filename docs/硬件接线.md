# 硬件接线与引脚映射

## 主控

STM32F103C8T6（"蓝板" / 最小系统板），72 MHz，USB CDC 虚拟串口。

## 引脚映射表

| 功能 | 引脚 | 定时器/外设 | 说明 |
|---|---|---|---|
| 电机 A PWM | PA6 | TIM3_CH1 | 10 kHz，ARR=9999，PSC=71 |
| 电机 A 方向 IN1 | PB12 | GPIO 推挽输出 | 正转=高 |
| 电机 A 方向 IN2 | PB13 | GPIO 推挽输出 | 反转=高 |
| 电机 B PWM | PB1 | TIM3_CH4 | 10 kHz |
| 电机 B 方向 IN1 | PB14 | GPIO 推挽输出 | 正转=高 |
| 电机 B 方向 IN2 | PB15 | GPIO 推挽输出 | 反转=高 |
| USB D- / D+ | PA11 / PA12 | USB | 虚拟串口 |
| 编码器 A | PA0 / PA1 | TIM2_CH1 / CH2 | 编码器模式，闭环时接入 |
| 编码器 B | PB6 / PB7 | TIM4_CH1 / CH2 | 编码器模式，闭环时接入 |
| 心跳 LED | PA5 | GPIO | 板载 LED，5 ms 翻转 |

> 原工程里 TIM3_CH3(PB0) 也被配成 PWM，本项目中不用，`motor.c` 里保持输出 0。开环时不需要接编码器。

## 电机驱动（以 TB6612FNG 为例）

TB6612 是双路 H 桥，正好控制两个电机：

| TB6612 引脚 | 接 STM32 | 说明 |
|---|---|---|
| PWMA | PA6 | 电机 A 速度 |
| AIN1 | PB12 | 电机 A 方向 |
| AIN2 | PB13 | 电机 A 方向 |
| PWMB | PB1 | 电机 B 速度 |
| BIN1 | PB14 | 电机 B 方向 |
| BIN2 | PB15 | 电机 B 方向 |
| STBY | 3.3V 或一个 GPIO | 置高才能工作 |
| VM | 电机电源（如 12V） | **独立供电**，不要从 STM32 取电 |
| VCC | 3.3V | 逻辑电源 |
| GND | 共地 | 与 STM32 必须共地 |

### 方向真值表（每路相同）

| IN1 | IN2 | 电机状态 |
|---|---|---|
| 1 | 0 | 正转 |
| 0 | 1 | 反转 |
| 0 | 0 | 刹车（滑行） |
| 1 | 1 | 刹车（短接，本项目不用） |

## 上电顺序（安全）

1. **先不接电机**，只给 STM32 上电，确认 USB 枚举出 COM 口。
2. 用 `motor_host.py --port COMx` 发 `S0`，确认能收到 `OK`。
3. 关电源，接好电机与驱动，**电机驱动独立供电**，确认共地。
4. 再上电，发小速度 `S+100`，观察两个电机是否按 0.5 比例转（A 快、B 慢）。
5. 确认方向正确、比例正确后，再逐步加大速度。
6. 要测闭环，先接好编码器，用 `E` 看计数是否随转动变化；方向反了改 `encoder.h` 里的 `ENCODER_A_DIR` / `ENCODER_B_DIR`，满速计数率改 `ENCODER_FULL_CPS`，然后发 `L1`。
7. 随时准备按 `X` 急停。500 ms 不发任何命令设备会自动刹车。

## 常见问题

| 现象 | 排查 |
|---|---|
| 电机完全不转 | STBY 是否置高；VM 是否供电；共地是否接好 |
| 只有一个电机转 | 检查对应 PWM 通道与方向脚接线 |
| 两电机转向相反 | 对调该电机两根线，或交换其 IN1/IN2 |
| 转但对调了快慢 | 检查 K 值；或 A/B 的 PWM 通道接反 |
| 电机有啸叫 | PWM 10 kHz 正常现象；提高电压或换驱动频率 |
| USB 识别不稳定 | 换数据线；电机电源加 100µF 电容滤波 |
